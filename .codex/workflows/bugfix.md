# Bugfix

Follow the [lifecycle](lifecycle.md) and [approval policy](../../AGENTS.md).
Use the [bugfix templates](../../specs/templates/bugfix/README.md).
Capture expected/actual behavior, reproduction, affected versions and impact.
Athena verifies the root cause with evidence and identifies regression risks.
Reuse current adoption evidence; propose a focused fix and regression test.
Preserve requirements and development gates, then run implementation, testing,
independent review, approved adjustments, and authorized Git/release actions.
Do not combine a fix with unrelated refactoring.
