# Commit

## Purpose
Prepare and create a safe, traceable local commit.

## Role
Verify readiness and use the GNO commit convention.

## Inputs
Requirements, testing/review/validation reports, understood working tree, and commit approval.

## Approved References
Approved project documents, Git status, and all preceding reports.

## Process
Verify requirements, testing, review, required adjustments, validation, and
working-tree scope; write `11_commit_summary.md`; propose `<type>: <description>`
using feat, fix, build, chore, ci, docs, perf, refactor, revert, style, or test.

## Restrictions
No scopes, vague messages, unapproved commit, or push.

## Outputs
Commit summary and, after approval, local commit.

## Approval Requirements
Explicit commit approval is required; it does not authorize push.

## Next-stage Handoff Information
Repository, branch, hash, message, files, and validation statuses.
