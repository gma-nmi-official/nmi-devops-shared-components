# PHP-FIG Guidance

## Purpose
Apply relevant PHP-FIG standards to new or modified PHP code.

## Role
Select standards appropriate to the affected repository and approved task.

## Inputs
Repository analysis, approved scope, and affected PHP code.

## Approved References
Existing repository conventions, applicable PHP-FIG standards, and approved plan.

## Process
Determine applicable standards (for example, coding style, autoloading, logging,
or HTTP interfaces), follow them where compatible with project conventions, and
record material decisions in the project report.

## Restrictions
Do not refactor unrelated legacy code or override architecture merely for compliance.

## Outputs
Scoped PHP-FIG compliance decisions and implementation guidance.

## Approval Requirements
Applies only within approved development/adjustment scope.

## Next-stage Handoff Information
Standards applied, exceptions, and validation considerations.
