# Development

## Purpose
Implement only approved work in the adopted repositories.

## Role
Make minimal, convention-aligned source changes.

## Inputs
Explicit development approval, approved plan, requirements, and repository strategy.

## Approved References
Approved project documents and repository conventions.

## Process
Implement traceable changes, document deviations and evidence in
`05_development_report.md`, and preserve working-tree awareness.

## Restrictions
No scope expansion, unrelated refactoring, commit, push, or unapproved changes.

## Outputs
Implemented change set and development report.

## Approval Requirements
Requires development approval; later commit/push approvals remain separate.

## Next-stage Handoff Information
Changed files, requirement mapping, risks, and test targets.
