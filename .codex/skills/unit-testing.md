# Unit Testing

## Purpose
Validate approved requirements against the implemented change.

## Role
Execute the project-appropriate tests and report evidence.

## Inputs
Approved requirements, implementation, and development report.

## Approved References
Approved project documents and implementation under test.

## Process
Test only approved scope; for each requirement record scenario, expected and
actual result, PASS/FAIL, evidence, failures, recommendation, and next action
in `06_unit_testing_report.md`. Use browser tooling when appropriate.

## Restrictions
No exploratory testing as a substitute for requirement validation or source changes.

## Outputs
Requirement-driven testing report.

## Approval Requirements
Failures stop progression and return to an approved corrective path.

## Next-stage Handoff Information
Test status, evidence, failed requirements, and review-ready scope.
