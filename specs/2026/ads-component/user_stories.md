# User stories: Ads component

| ID | Story | Acceptance link |
| --- | --- | --- |
| ADS-US01 | As a consumer, I can place a configured MREC slot in a page region so the ad provider renders the correct unit and responsive sizes there. | ADS-AC02-ADS-AC10 |
| ADS-US02 | As a consumer, I can place a responsive leaderboard that selects desktop or mobile inventory and approved sizes from configured breakpoints. | ADS-AC02-ADS-AC10 |
| ADS-US03 | As a consumer, I can provide my provider instance, inventory IDs, targeting, consent eligibility, and no-fill policy without the package loading production scripts or inventing values. | ADS-AC04-ADS-AC15 |
| ADS-US04 | As a page visitor, I see an accessible ad label and a stable slot area; when no ad fills, the configured empty-slot behavior is applied without a layout or runtime failure. | ADS-AC09-ADS-AC14 |
| ADS-US05 | As a developer, I can test ad slots in Storybook and automated tests with a fake provider and inspect responsive, loading, empty, and error states without live ad traffic. | ADS-AC11-ADS-AC18 |
